# 나만의 도트 편집기

캐릭터·이모티콘·도트 그림을 그리는 브라우저 편집기. 설치 없이 `index.html` 하나로 돌아간다 (PC · 아이패드 · 휴대폰).

https://han8877.github.io/mydotedit/

## 할 수 있는 것

- **도구**: 연필 · 지우개 · 채우기 · 추출(스포이드) · 직선 · 네모 · 원 · 명암 · 선택/옮기기 · 레이어 이동 · 글자 · 손
- **색**: 색상판(투명도 포함) · 색 코드 입력 · 팔레트 여러 벌 · 내 팔레트 · 이 그림에 쓴 색 · **최근 쓴 색 자동 저장**
- **앞·뒤·왼쪽·오른쪽 모습**을 따로 그리기 (오른쪽은 왼쪽을 뒤집어 자동으로) · 네 방향 미리보기 · 빙글빙글 돌려보기
- **레이어** (보이기·잠그기·투명도·합치기) · **프레임** 애니메이션 · 겹쳐보기
- 좌우 대칭 그리기 · 깔끔한 선 · 체크무늬 · 외곽선 자동 · 색 일괄 바꾸기 · 뒤집기 · 밑그림 따라 그리기
- **PNG 저장 (배경 없음)**: 한 장 · 4방향 한 줄 · 시트 · 여러 파일 · 1~16배 크기
- 작업 자동 저장 (이 브라우저) · 작업 파일(.json) 저장·불러오기 · PNG 불러오기

단축키는 화면의 **도움말** 버튼에 있다.
